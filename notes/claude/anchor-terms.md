Some decent, neutral starter anchor terms, avoiding the key terms of
interest.

善 -> good
惡 -> bad? / vicious?
治 -> govern?
始 -> begin?
才 -> ability / capability
變 -> change
大 -> large / great
學 -> study
知 -> know / knowledge?
女 -> woman
政 -> politics / political
物 / 事 -> thing
欲 -> desire / want
上 -> high
下 -> low

A possibly interesting consequence: the more of these that I add, the
_further_ 仁 and 義 move from their usual 'virtue' translations, and towards
"justice,"

## Reusing anchors

The same term can be assigned to multiple terms in the other langauge as an
anchor term. But this doubles the weight given to that term; it has twice as
much force on realigning the rest of the space. So this should be reserved
for particularly clear terms, and maybe should be communicated to the user.
