### How it affects my work

From my experience on this project, vibe coding discourages some of this behavior (leave the details up to Claude!) but the possibility of doing so much so quickly also makes it tempting to forging ahead with new features / fixes when it would be better to slow down and assess where things are at. I often had two Claude Code agents running on different branches, one working on a frontend feature and another on the NLP pipeline. This certainly sped things up at times. But GAI works so quickly that the frequent nudges to view the work and (verbose) explanations from each agent created its own feedback loop that could pull me in for hours at a time.
